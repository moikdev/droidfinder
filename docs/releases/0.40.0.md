# Findroid 0.40.0-preview

Choose a local library once, then search its saved metadata snapshot when you want. Live folders remain the default.

Open **More → Search index… → Add local folder…** and confirm the folder to scan. In **Search criteria**, choose **Live folders** or **Local index**. Opening a saved search or importing a setup never registers folders or starts indexing.

- Save filenames, paths, types, sizes and modification dates on the tablet. Document contents and tags are not copied into the index, and nothing is uploaded.
- See snapshot dates, entry counts, current folder availability, observed-change hints and measured storage use.
- Refresh manually, pause, restart, remove a folder or delete the cache. Failed, capped, paused and interrupted refreshes retain the previous complete snapshot. Resume restarts the scan.
- Recheck admitted cached candidates with current metadata, tags and text criteria. Missing files, replaced roots and symbolic-link escapes do not become actionable cached results.
- Review uncovered folders and partial results in **Result details**, with **Use live folders** for a new folder scan. Newly created or renamed paths, or changed metadata that did not match the older snapshot, may be missed until refresh.
- Keep source choices independent across tabs, Smart Folders, workspaces, recent searches and setup backups. Indexed root registrations and cached rows are excluded from those backups.
- Keep documents, Favorites, tags and saved searches when deleting the index.
- Recheck an unavailable Favorite after a fast refresh when its original folder returns.

Named tablet controls are available in More, the action launcher and Advanced preferences. There are no new permanent toolbar icons and no scheduled indexing jobs.
