# Findroid 0.51.0-preview — read-only Office previews

Open a DOCX, XLSX or PPTX document in Quick Look. Read stored Word text, inspect worksheet names and values, or move through slide text in presentation order. Copy the loaded section and find matching rows. Your source document stays unchanged.

This is a text/value preview. Page layout and formatting can differ. Formulas are not recalculated; missing cached results are labelled. Preview limits explains the supported formats, omitted content and bounded partial previews. Password-protected and older Office formats need another app.
