Findroid is a native Android file explorer inspired by macOS Finder, with a tablet-first layout and phone support. This public preview brings together the work since the 0.24 release.

## Install

Download **Findroid-0.29.0-preview.apk** below and open it on Android 11 or newer. This is the optimized, installable development-signed build. The unsigned APK is for developers.

Findroid uses `dev.findroid`, a new app ID from version 0.26. It installs separately from older DroidFinder releases. Copy important files out of the old app’s private Workspace before uninstalling it.

## Highlights

- A clearer tablet toolbar: one view menu, Search, New folder and More, with named actions when files are selected.
- In-app updates from this repository, available at **More → App updates** and in Preferences. Optional daily checks, requested downloads, progress, cancellation, retry and restart recovery.
- APK size, checksum, package, version, Android compatibility and signing-certificate checks before Android confirms installation.
- Phone portrait/landscape layouts and distinct touch/mouse behavior: tap to open; mouse click to select and double-click to open.
- Natural filename sorting across views, searches and archives, including `Photo 2` before `Photo 10`.
- Multi-tag search, configurable scan depth and exclusions, and the Findroid rebrand.
- Safer deletion and transfer recovery, bounded ZIP indexing, Android 11 ZIP64 support, provider reconnect fixes, backup exclusions and dependency checks.

## Features to try

Preview PDFs, photos, Markdown, CSV, JSON and media with Peek / Quick Look. Open two panes to organize files between locations. Use tags, collections and Smart Folders to bring a project together without moving everything. Review batch renames, filename conflicts and transfer results before continuing.

## Updates and data

Install future updates over the existing Findroid app; do not uninstall first. Uninstalling or clearing data deletes its private Workspace, Trash and metadata. This preview uses the existing development signing key. The updater uploads no file content or credentials; connected cloud storage uses Android document providers.
