# Findroid 0.43.0-preview

For an important copy, choose **Paste and verify…** or **Duplicate and verify…**. Review the selected sources and destination, then choose **Copy and verify**. A folder's menu also offers **Paste into folder and verify…** when copied items are available. Cancel starts no work.

Findroid calculates SHA-256 while copying each source file, then reads the unfinished destination back and compares its actual byte count and digest before publishing it. This works with nested folders and files whose provider omits a size. A mismatch or unreadable copy fails safely, keeps the source and removes unpublished staging where possible. A failed reviewed replacement restores the previous destination through the existing recovery path.

**More → Transfers → Details** saves the results for each file, including verified copies, skipped items, read failures, mismatches and incomplete work. A checked file in an unpublished failed folder does not claim a completed copy. Pause, cancellation and retry preserve the request; verification reads do not inflate the copied-byte total. Transfers shows provider filenames when available and uses **Source item** when a name is unavailable.

Verification adds destination reads, supports copies, and stores up to 10,000 file results per transfer. Providers must allow reading their newly written files. SHA-256 describes the bytes checked at that time. See the [copy verification guide](../COPY-VERIFICATION.md).
