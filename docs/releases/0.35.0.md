## Clearer tablet commands and reachable Undo

**Findroid 0.35.0 preview** keeps Search, New folder and More in the same order when you browse, select files, search or edit the address. Narrow tablets and enlarged text move the named commands into another row. More groups tools by task.

Selecting files shows their count, location and **Selection actions** beside the file list. Each pane keeps its own selection controls, and only the active pane exposes the named Drag handle. File icons continue to support dragging into folders, Favorites and other Android apps.

Unavailable file commands stay interactive and explain what can help:

- Read-only Rename and Move offer copying to another folder.
- Commands waiting for a current operation offer View transfers. Choosing queued transfers and copying a selection to the clipboard remain available.
- Disconnected storage offers Storage locations, while library/search views can choose a real destination folder.
- Paste, extraction and other-pane destinations explain their own requirements.
- Keyboard commands and the searchable action launcher use the same policy and preserve the existing operation checks.

Open **More → Recent actions…** for eligible operations, affected names/locations and guarded Undo/Redo. Actions run in order; the list identifies what is next. Later edits stop recovery, and the reason remains visible when you reopen Recent actions. Partial retries preserve completed steps. The list is shared across panes/windows, bounded to 50 actions and kept only for the current app process. It resets when the process ends; it is separate from persistent transfer recovery.

The tag library keeps its results scrollable when the software keyboard reduces the available height. Its search fields and the conflict rename field provide a Done action, so you can return to the result or confirmation controls.

[Commands and Undo guide](../COMMANDS-AND-UNDO.md).

This increment addresses proposals **2, 3 and 6**. Its public acceptance status is recorded in [validation](../../VALIDATION.md) and [the tracker](../IMPROVEMENT-TRACKER.md). Physical tablet, TalkBack, removable-media and actual third-party provider acceptance remain separate.

## Install or update

From **0.30 or newer**, use **More → App updates** and confirm Android's installation prompt. You can also install **Findroid-0.35.0-preview.apk** over your existing app. Keep Findroid installed during upgrades to retain its private Workspace and settings. Version 0.29 needs one manual install because it predates the repository-address fix.

Android 11 or newer is required. This is an optimized, development-signed preview. The unsigned APK is for developers. Source, screenshots, checksums, the OTA manifest, build information and a public validation archive accompany the release.
