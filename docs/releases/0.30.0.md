## Drag files into another Android app

**Findroid 0.30.0 preview** restores the missing touch drag control and adds direct touch/pen dragging from file icons. Open Findroid beside a receiving app in split screen, hold a file icon and drop it into the other app.

- For several files, select them and hold the labeled **Drag** control, or hold one selected file icon.
- Mouse users can drag file icons directly.
- Mixed image/document selections advertise all selected file types.
- Local and connected-provider files use temporary, read-only Android URI grants. Other apps receive copies; the originals remain in Findroid.
- Tapping Drag explains the gesture. Drag feedback explains the copy behavior outside the app.
- Internal moves, copies, spring-loaded folders, cancellation and Undo remain supported.

The destination app must accept Android file drops. Use Share for other destinations; folder selections retain internal dragging and can be shared as ZIPs.

## Install or update

Download **Findroid-0.30.0-preview.apk** below and install it over Findroid to keep your files and settings. Android 11 or newer is required.

The repository was renamed to `moikdev/findroid` after 0.29 was published. That version's updater rejects the renamed feed, so this first update requires the APK. Version 0.30 uses the current repository and accepts the known legacy release URLs; subsequent updates use **More → App updates**.

This is an optimized, development-signed preview. The unsigned APK is for developers. Source, screenshots, APK checksums, the OTA manifest, build information and validation evidence are published with this release.

The separate-UID QA receiver is not included in the shipping app. Native tests cover actual split-screen drops and temporary grant scope; the validation record documents the exact device runs and remaining third-party app/hardware coverage.
