## Take your setup with you

**Findroid 0.33.0 preview** adds whole-setup backup and reviewed restore, with explicit folder mapping when moving to another tablet.

- Open **Preferences → Back up or restore setup…**, **Organize → Back up or restore all setup…**, or search for **setup** in the action launcher.
- Back up Favorites and groups, tags and assignments, collections, Smart Folders and their rules, workspaces, open tabs, folder appearance, rename presets, and browsing/archive preferences in one JSON file.
- Choose the sections to restore. **Merge** keeps your current Favorite labels/order and preferences, combines organization references, and gives changed layouts/searches/presets a clear restored name. **Replace** uses the selected backup sections.
- Choose replacement storage roots and review missing references before applying. Provider mappings use returned document IDs, support read-only folders, and explain missing, ambiguous, loading, or unrecorded references.
- Imported open tabs become a **Restored open tabs** workspace. Open it from the completion screen when you want to switch.
- A private previous-setup copy and rollback journal protect metadata restoration. Interrupted prepared restores roll back before browsing starts; damaged recovery data keeps the recovery gate visible for retry.

The backup contains setup metadata, including names and paths. **Keep it private. Copy your actual files separately, and reconnect Android storage permissions on the new device.** It does not contain document bytes, account sign-ins, access grants, transfer/Undo history, Trash, or updater state. See [the setup guide](../SETUP-BACKUP.md) for merge rules, format limits, and provider restrictions.

This increment implements proposals **55, 56, and 61**. **16 of 72 proposals are implemented; 56 remain open or partial.** The [improvement tracker](../IMPROVEMENT-TRACKER.md) records the remaining work. Physical tablets, removable drives, TalkBack, and actual third-party providers still require separate acceptance.

## Install or update

From **0.30 or newer**, open **More → App updates**, download this version, and confirm Android's installation prompt. You can also install **Findroid-0.33.0-preview.apk** over your existing app. Keep the app installed during upgrades to retain its private Workspace and settings.

From **0.29**, install this APK manually once; that version predates the repository-address fix in the updater. Android 11 or newer is required. This is an optimized, development-signed preview; the unsigned APK is for developers.

Debug/preview/unsigned builds pass; lint has zero errors, 143 warnings and 11 hints. The release includes actual Android screenshots, build information, checksums, an OTA manifest and a whitelisted validation archive.

Public acceptance also passes: all five immutable assets match anonymous downloads; a real **0.32 → 0.33** in-app download and Android installation succeeds on API30 with original-file/Favorite/preference preservation and no repeat offer. The final validation archive is downloaded and checked separately after those results are included.
