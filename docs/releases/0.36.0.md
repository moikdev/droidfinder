## Search results with clear explanations

**Findroid 0.36.0 preview** highlights matching filename words and explains which name, tag, metadata or text-content criteria matched. Content searches include a short plain-text snippet captured during the original read. List, Icons, Columns and Gallery all show match information; the preview/details pane provides more room for it.

The criteria editor adds **Today**, **This week**, **This month**, **Under 1 MB**, **Over 1 GB** and **Images**. Calendar choices follow the local date, time zone and first day of the week, and update on refresh. Older “Today” searches retain their rolling 24-hour behavior. Expert size fields preserve exact bytes instead of rounding imported values.

**Exact exclusions** let you omit one file or one folder and its descendants while keeping same-named folders elsewhere. Choose a folder in the actual picker or exclude the current selection, review the list, and apply. Exact locations survive saved searches and reviewed setup restore. Providers that cannot verify ancestry produce an incomplete-result explanation.

Snippets stay in the current listing's memory. Saved tabs, Smart Folders, workspaces and setup exports contain criteria and references without snippet text. Original documents remain untouched.

## Install or update

From **0.30 or newer**, open **More → App updates** and confirm Android's installation prompt. You can also install **Findroid-0.36.0-preview.apk** over the existing app. Keep Findroid installed during upgrades to retain its Workspace and settings. Version 0.29 needs one manual install because it predates the repository-address fix.

Android 11 or newer is required. This is an optimized, development-signed preview; the unsigned APK is for developers. The public release includes source, checksums, the OTA manifest, build information and a validation archive.
