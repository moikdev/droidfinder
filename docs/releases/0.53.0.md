# Findroid 0.53.0 preview

Findroid 0.53 adds a dedicated photo review for Android tablets.

- Select up to 200 images, browse thumbnails in the existing zoomable viewer, and flag candidates without changing the browser's selection.
- Filter to flagged candidates and compare any current image with a pinned reference using linked side-by-side previews.
- Open **Tag flagged…**, review the exact selection and proposed changes, then apply tags with the existing stale-file checks and session Undo/Redo.
- Keep flags, order and reference through activity recreation. Closing the review or losing the app process discards session flags; applied tags remain saved.
- Image controls wrap and scroll at larger text sizes, preserving room for the photo.

Review does not rewrite photo bytes or EXIF. Flags are temporary candidate decisions. Existing image-viewer and file-comparison limits apply. This is a development-signed preview. Physical tablets, third-party providers and screen-reader acceptance remain open.
