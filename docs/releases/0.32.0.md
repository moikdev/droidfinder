## Favorites that stay in your order

**Findroid 0.32.0 preview** delivers the first sidebar, browsing-clarity and navigation increment of the authorized improvement list.

- Hold a favorite's folder icon and drag it to the blue insertion line. With a mouse, drag directly. Order survives restarting the app; the original folder never moves.
- Each shortcut has an Options menu: rename its label, reveal the original, open a new tab/pane, move up/down or into a group, repair its location, or remove the shortcut.
- Create collapsible favorite groups. Hide/reorder the seven built-in Favorites locations and restore their defaults without losing your custom shortcuts.
- Unavailable folders explain the problem and offer reconnect/repair. Identical shortcut names show paths. Existing favorites migrate from their old unordered set.
- Find commands and folders through More or **Ctrl+Shift+P**. **Ctrl+K** opens the folder switcher with Favorites, breadcrumbs, current-folder children and recent tab destinations. Arrow keys, Enter and Escape work throughout. Full paths are rechecked before opening; unavailable commands explain why.
- Replayable gesture tips, selection counts tied to each pane, clear-search/show-hidden empty states, and full destination feedback make everyday actions easier to understand.
- Browsing and Advanced preferences separate normal choices from conflict handling, archive budgets and cache maintenance. Short-window empty states keep their actions reachable when the keyboard is open.

These changes implement 13 proposals from the 72-item scope. Command explanations have begun in the launcher; broader per-menu explanations remain open. Setup backup, indexing, network protocols, durable Undo, physical input/storage acceptance and the remaining roadmap are still in progress. See `docs/IMPROVEMENT-TRACKER.md` and `docs/SIDEBAR-AND-NAVIGATION.md` in the public source.

## Install or update

From **0.30 or newer**, open **More → App updates**, download this version, and confirm Android's installation prompt. Or install **Findroid-0.32.0-preview.apk** over your current app.

From **0.29**, manually install this APK once over the existing app. That version predates the updater fix for the repository rename. Keep the app installed during the upgrade to retain its Workspace and settings.

Android 11 or newer is required. This is an optimized, development-signed preview. The unsigned APK is for developers. The release includes source, actual Android screenshots, checksums, the update manifest, build information and a validation archive. Physical-device and third-party-provider coverage remains separate from emulator evidence.

Local validation: **317 JVM tests**, **79/79 native cases on each API30/API36 tablet emulator**, optimized legacy-upgrade/native-reorder/restart/original-byte acceptance, and zero lint errors. Actual normal and enlarged-text screenshots and precise coverage accompany the validation archive. Physical input/storage/provider acceptance remains open.

Public acceptance: a real **0.31 → 0.32** in-app download and Android installer upgrade passes on API 30, with the installed APK matching the public bytes and synthetic file/favorite/preference preservation verified. The production-source public APK/signature check passes on API 36, and the updated app reports up to date. Both tablets are restored to the exact public optimized APK.
