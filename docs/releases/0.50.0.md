# Findroid 0.50.0-preview — optional local text recognition

Choose **Recognize image text…** in an image preview, or **Recognize page text…** on the current PDF page. Choose English or Japanese and explicitly download or import its verified language model. Installed languages work offline; your document stays unchanged.

Recognition runs in a separate private worker. Review the result, select or copy its text, and find words using Previous/Next. Stop or close OCR to cancel the request. This recognizes one image or PDF page and respects existing PDF extraction restrictions.

Language removal and incomplete-download cleanup require a review. Invalid models cannot become active. Storage-review errors offer an explicit retry. Opening the preview or dialog starts neither recognition nor a download.

Local acceptance passes: 964 JVM cases, zero lint errors, 45 matching native image/PDF/OCR cases per Android 11/16 tablet, real model download/import and cold-start workflows, and 12 optimized font/theme/size layouts per API with actual clipboard and raster-glyph checks. The source documents and original tablet state are preserved. Public OTA and independent immutable-archive acceptance remain pending; proposal 47 is still open and 37/72 proposals are implemented. Earlier checker stops remain retained and disclosed in the validation record.
