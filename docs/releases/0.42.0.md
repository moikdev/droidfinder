# Findroid 0.42.0-preview

Transfers now explain the work currently happening. Recent speed responds to changing storage performance, remaining time is labeled **left in this phase**, and slow source, destination and provider calls get a specific waiting message. Paused and stale estimates disappear.

Preparation reports inspected items. Verification counts bytes checked separately, so reading a completed copy again does not inflate the transferred-byte total. Unknown-size provider files can show a recent speed and bytes processed without an invented total or ETA. Transfers, the compact strip and the Android notification share these summaries.

See [Transfer progress](../TRANSFER-PROGRESS.md) for the sample window, expiry rules and provider limits. The foreground sampler runs only while an operation is active.

Local acceptance passes: 525 JVM checks, 405 identical native cases per API30/API36 tablet in 47 fresh-process batches, and optimized upgrade, real-provider copy/wait/recovery, pause/resume, cancellation and six layout configurations. Original files, preferences, databases, cache bytes and URI grants are preserved. All 40 optimized screenshots were inspected.

Public OTA and immutable evidence acceptance are being completed. Proposal 39 remains in progress until both are independently verified.
