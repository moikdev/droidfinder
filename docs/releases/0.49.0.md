# Findroid 0.49.0-preview — select text on PDF pages

Proposal 46 is in release acceptance. The implemented-proposal total remains 36/72 until the complete native, optimized-tablet, actual public OTA and immutable-archive checks finish.

Choose **Select page text** in a PDF preview, or hold a rendered word to begin. Touch a word, drag across lines, and adjust the named start/end handles. **Copy selection** copies extracted text with its line breaks. **Select all page text** and **Clear selection** are available beside it.

**Pan and zoom** retains the highlight and Copy/Clear actions. Move the zoomed page, then return to **Select page text** to adjust the handles. Ctrl/Cmd+A and Ctrl/Cmd+C work in the page selection; Escape leaves it. Search fields keep their editing shortcuts. Another page, a closed preview or the reflowed reading view clears the rendered-page selection.

The existing PDF text layer supplies the selected text. Scanned pages without text, extraction permissions and partial results are explained. Grouped text runs remain indivisible; the text summary helps check unusual embedded text. The document is unchanged. Extraction and glyph-index limits remain bounded, cancellable and local.

Frozen candidate 2 passes all 948 JVM cases. Both exact optimized previews pass the four core workflows and six actual foreground clipboard reads per API. All ten core screenshots were inspected. API30 also passes the complete 12-layout, two-density matrix; all 26 surface screenshots and 12 actual text-glyph crops were inspected. The complete 563-case native regressions, API36 layouts and actual public OTA remain pending.

The first optimized candidate exposed overlapping handle touch targets through Android accessibility. Candidate 2 separates intersecting targets while retaining the visible knobs near the glyphs. An API36 archive-opening timeout and a transient native-menu hierarchy stop remain preserved and excluded. Their detailed reviews are recorded with the acceptance evidence; original files, metadata, URI grants and display settings were restored after each stopped attempt.
