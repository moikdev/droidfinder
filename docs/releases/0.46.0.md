# Findroid 0.46.0-preview — review before synchronizing

Local and actual public OTA acceptance are complete. Independent verification of the immutable validation archive is pending; proposal 43 remains open until that check finishes.

Open a local folder in each pane, then choose **More → Compare folders… → Review synchronization…**. Choose a direction and review the complete source and destination paths. Findroid checks file contents, includes hidden files and shows every child of a newly added folder.

New items are selected first. Replacing different destination contents and moving destination-only items to Trash each need their own selection and confirmation. Existing originals move to Findroid’s Trash before a replacement is published. Dates never choose a winner, and a file/folder type conflict stays a manual decision.

The review and confirmation screens scroll on a tablet. The feature uses named commands in the existing More menu. Tags, folder appearance and references follow verified changes. Completed additions can use supported saved Undo. Runs containing replacements or destination-only Trash moves keep Undo for the current app session; originals remain in Trash after restart.

**More → Synchronization records…** shows the run intents saved before preparation, including the source, destination, working folder and journal location. A record does not prove completion. Opening a record never retries an operation, restores a file or removes working data. Changed files, occupied names, lost access and ambiguous interrupted moves stop for manual review.

This increment supports separate local folders on storage that supports the required atomic rename. Android 11 shared storage on the assigned emulator refuses publication; Findroid stops and preserves its working data. Workspace is the tested option there. Original preservation needs the destination and Findroid’s Trash on the same filesystem. Provider folders, overlapping roots, links, special files and automatic synchronization schedules are outside this increment. See the [synchronization guide](../REVIEWED-FOLDER-SYNC.md) for supported storage, working data, Undo and recovery boundaries.
