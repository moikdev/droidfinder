# Findroid 0.41.0 preview — understand available file actions

Available as a development-signed preview for Android 11 and newer.

**More → Available actions…** explains Read, Create items, Change contents, Rename, Delete and Move to Trash for the current folder or selected items in the active pane. The same named command is available in context menus and Find action. It adds no permanent toolbar icon.

The window uses cached information from the last folder load. **Refresh access info** explicitly reloads Android's saved permissions and folder information in the background. A slow provider is not contacted just to show a menu or explanation.

- Each document keeps its own capability evidence. A connected folder cannot authorize mutations on all its children.
- Missing, null or malformed flags are **Not reported**. Explicit zero flags, read-only saved grants, missing locations and protected roots have their own explanations.
- Mixed selections have exact counts for each action and up to three named examples, prioritizing unavailable items.
- Blocked rename, removal and creation commands explain the affected document and offer Copy or Storage locations where useful. Busy, empty-selection and Trash rules retain precedence.
- Provider Trash is explained as a local Findroid recovery copy followed by deletion of the original. It does not use the provider's own Trash; restoring may create new document addresses.
